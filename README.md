# תחום אי־וודאות — אוסף שאלות להדפסה 📐

חוברת שאלות בסטטיסטיקה והסתברות לחטיבת הביניים (כיתות ז'–ח'), שנבנתה מתוך מסמך
"תחום אי־וודאות". המסמך שולף **רק את השאלות** (ללא הערות הדידקטיקה) ומציג אותן
בעיצוב מחודש, נקי ומוכן להדפסה ב־A4, כולל שחזור איכותי של כל הדיאגרמות כגרפיקה וקטורית.

> **התוצר המוכן להדפסה:** [`תחום-אי-ודאות-שאלות.pdf`](./תחום-אי-ודאות-שאלות.pdf) · 43 עמודי A4 · 54 שאלות
>
> 🌐 **אפליקציה (דף נחיתה):** [`index.html`](./index.html) — כפתורי צפייה, הורדה וקישור · 📖 **תצוגת דפים:** [`viewer.html`](./viewer.html)

---

## מה יש בחוברת

7 פרקים ממוספרים בצבע, כל אחד בעמוד נפרד:

| פרק | נושא | דוגמאות |
|----|------|---------|
| א | איסוף וארגון נתונים | עמודות, מקלות, עוגה, פיזור, "מצעד הלהיטים", USB |
| ב | שכיחות יחסית | דילמת הצומת, הקלע המצטיין, גלגל המזל, פיקטוגרם |
| ג | מדדי מרכז | טווח/שכיח/חציון/ממוצע, שביעות רצון, זמן מסך |
| ד | הסתברות | עטים, גשם, קוביות וסימטריה |
| ה | אינטרפולציה | שכר, אוכלוסייה, חשמל, ריצה |
| ו | אקסטרפולציה | גרף מצטבר + מכירת כרטיסים |
| ז | פירוש משני מקורות מידע | קפיצה לרוחק, משבר הקפה |

כמעט כל הדיאגרמות נבנו מחדש כ־SVG חד ומדויק (עמודות, מקלות, עוגות, פיזור, גרפים קוויים,
גלגל מזל צבעוני, פיקטוגרם, גרפים מטעים בעלי ציר קטוע ועוד). שני איורים בלבד, שבהם דיוק
היחסים קריטי (עוגת "תכניות הטלוויזיה" מ־TIMSS ושאלת ייצוגי כלי־הרכב), נשמרו כתמונה
מהמקור באבחנה גבוהה.

## מבנה הריפו

```
.
├── index.html                ← אפליקציה: דף נחיתה עם כפתורי פעולה בעברית
├── viewer.html               ← תצוגת דפים איכותית (גלריית A4)
├── תחום-אי-ודאות-שאלות.pdf   ← התוצר המוכן להדפסה / הורדה (A4)
├── worksheet.html            ← אותה חוברת כ־HTML
├── build.py                  ← מרכיב את החוברת, מפיק PDF, אפליקציה ותצוגה
├── charts.py                 ← פונקציות עזר לבניית הדיאגרמות (SVG)
└── assets/
    ├── tv_pie.png            ← עוגת "תכניות טלוויזיה" (TIMSS)
    ├── vehicles_options.png  ← ארבעת ייצוגי כלי־הרכב לבחירה
    └── pages/                ← תמונות העמודים (עבור viewer.html)
```

## האפליקציה

`index.html` הוא דף נחיתה מעוצב (RTL, צבעי פרימיום) עם שלושה כפתורי פעולה:
**📖 צפייה בדפים** (פותח את `viewer.html`), **⬇ הורדת ה־PDF**, ו־**🔗 GitHub**.
ניתן לפתוח אותו מקומית בדפדפן, או דרך GitHub Pages.

---

## בנייה מחדש

```bash
pip install pymupdf playwright
playwright install chromium
python build.py
```

הסקריפט מפיק את `worksheet.html`, את קובץ ה־PDF, את תמונות העמודים (`assets/pages/`),
ואת `viewer.html` ו־`index.html` (האפליקציה).

### עריכה
את התוכן, הצבעים, מקום התשובות והדיאגרמות עורכים ב־`build.py` (וב־`charts.py`
עבור הגרפיקה) ומריצים שוב את `python build.py`.
