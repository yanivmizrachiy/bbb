# תחום אי־וודאות — אוסף שאלות להדפסה 📐

חוברת שאלות בסטטיסטיקה והסתברות לחטיבת הביניים (כיתות ז'–ח'), שנבנתה מתוך מסמך
"תחום אי־וודאות". המערכת שולפת **רק את השאלות** (ללא הערות הדידקטיקה), מעצבת אותן
מחדש בעיצוב נקי ומוכן להדפסה ב־A4, ובונה אפליקציית נחיתה נוחה לצפייה ולהורדה.

🌐 **אפליקציה חיה:** https://yanivmizrachiy.github.io/bbb/
📄 **PDF להדפסה:** [`תחום-אי-ודאות-שאלות.pdf`](./תחום-אי-ודאות-שאלות.pdf) · 43 עמודי A4 · 54 שאלות

---

## האפליקציה

`index.html` — דף נחיתה מעוצב (RTL, צבעי פרימיום, מותאם לנייח ולנייד) עם כפתורי פעולה עדינים:

| כפתור | פעולה |
|------|-------|
| 📖 **צפייה בדפים** | פותח את `viewer.html` — תצוגת A4 איכותית לגלילה |
| ⬇ **הורדת ה־PDF** | הורדה ישירה של כל הדפים למכשיר |
| 🔗 **GitHub** | קישור חיצוני לקוד המקור |

בראש הדף מוצג קישור מסודר לשיתוף + כפתור העתקה.

## תוכן החוברת — 7 פרקים

| פרק | נושא | דוגמאות |
|----|------|---------|
| א | איסוף וארגון נתונים | עמודות, מקלות, עוגה, פיזור, "מצעד הלהיטים", USB, ייצוגי כלי־רכב |
| ב | שכיחות יחסית | דילמת הצומת, הקלע המצטיין, שני גלגלי מזל, פיקטוגרם |
| ג | מדדי מרכז | טווח / שכיח / חציון / ממוצע, שביעות רצון, זמן מסך |
| ד | הסתברות | עטים, גשם, קוביות וסימטריה |
| ה | אינטרפולציה | שכר, אוכלוסייה, חשמל, ריצה |
| ו | אקסטרפולציה | גרף מצטבר + מכירת כרטיסים |
| ז | פירוש משני מקורות מידע | קפיצה לרוחק, משבר הקפה |

המספור אוטומטי ורציף בכל פרק. כמעט כל הדיאגרמות נבנו מחדש כ־SVG חד ומדויק
(עמודות, מקלות, עוגות, פיזור, גרפים קוויים, גלגל מזל צבעוני, פיקטוגרם, גרפים מטעים
בעלי ציר קטוע ועוד). שני איורים בלבד, שבהם דיוק היחסים קריטי (עוגת "תכניות הטלוויזיה"
מ־TIMSS ושאלת ייצוגי כלי־הרכב), נשמרו כתמונה מהמקור באבחנה גבוהה.

## מבנה הריפו

```
.
├── index.html                ← אפליקציית הנחיתה (כפתורי פעולה בעברית)
├── viewer.html               ← תצוגת דפים איכותית (גלריית A4)
├── תחום-אי-ודאות-שאלות.pdf   ← התוצר להדפסה / הורדה
├── build.py                  ← מרכיב את החוברת, מפיק PDF, אפליקציה ותצוגה
├── charts.py                 ← פונקציות עזר לבניית הדיאגרמות (SVG)
└── assets/
    ├── tv_pie.png            ← עוגת "תכניות טלוויזיה" (TIMSS)
    ├── vehicles_options.png  ← ארבעת ייצוגי כלי־הרכב לבחירה
    └── pages/                ← תמונות העמודים (עבור viewer.html)
```

---

## בנייה מחדש

```bash
pip install pymupdf playwright
playwright install chromium
python build.py
```

הסקריפט מפיק את ה־PDF, את תמונות העמודים (`assets/pages/`), את `viewer.html`
ואת `index.html` (האפליקציה). את התוכן, הצבעים ומקום התשובות עורכים ב־`build.py`,
ואת הגרפיקה ב־`charts.py`, ומריצים שוב `python build.py`.
